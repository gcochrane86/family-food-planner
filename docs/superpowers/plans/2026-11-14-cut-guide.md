# Cut Guide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Tap an ingredient card to see its cut full screen, with a true-size ruler set once per device with a bank card.

**Architecture:** Pure `src/lib/cutGuide.ts` (sizes, meanings, ruler setting); one `src/components/CutGuide.tsx`
full-screen dialog; `Tile`/`Card` take `onTap`; Today's hour step tiles, the chopping list and cook mode open it.

**Spec:** `docs/superpowers/specs/2026-11-14-cut-guide-design.md`

## Global Constraints
- No migration. Pictures use `prep_photos` keys from `prepKey(name, note)` and `repo.generatePrepPhoto`.
- Holding a card keeps opening its options; the get-out list's tap still ticks (no guide there).
- Browser storage reads and writes are wrapped in try/catch; key `cut-ruler:px-per-mm`.

## Review Focus
1. A card with no note and no length amount: no tap action (nothing to show).
2. "3 cm" amount plus "2mm discs" note: both markers, labelled differently.
3. Ruler not set, or storage throws: picture and words still show, with Set the ruler.
4. A hold on a tile must not also open the guide.
5. Sizes longer than the screen: marker clamped, still labelled.

### Task 1: Cut words and sizes
- `cutGuide(name: string, qty: string, note: string | null): CutGuide | null` with
  `CutGuide { instruction: string; meaning: string | null; sizes: { mm: number; label: string }[]; square: number | null; prep: { key: string; label: string } }`.
  Sizes from the note (`3cm chunks` → `{30, '3cm chunks'}`, `2mm discs` → `{2, '2mm discs'}`) and a length amount
  (`3 cm` → `{30, '3cm piece'}`). `square`: the size in mm for chunks or diced. Null when there's no note and no length.
- `meaningOf(cut)` for chunks, diced, finely diced, strips, matchsticks, sliced, thinly sliced, rings, half-moons,
  discs, wedges, halved, quartered, crushed, grated, florets.
- `readPxPerMm(): number | null`, `savePxPerMm(v)`, `CARD_MM = 85.6` (long side; the card is drawn upright so it fits a phone).
- Tests: carrot 3cm chunks, ginger 3 cm + 2mm discs, spring onion 2mm rings, garlic peeled (no sizes), nothing → null; storage throwing → null.

### Task 2: The view
- `CutGuide` dialog (`aria-label="How to cut <name>"`): × Close; picture (`StoredPhoto`) or **Make the picture**;
  instruction; meaning; ruler down the left edge (cm numbers, mm ticks, a marker and label per size) and the life-size
  square; **Set the ruler again**. Not set: **Set the ruler** screen with a card outline, − / + and a slider, **Save**.
- `Card`/`Tile` take `onTap`. Tests: the view shows marker labels at the saved scale; set-the-ruler saves; Make the picture calls the maker.

### Task 3: Wire it in
- Today's hour step tiles and chopping rows; cook mode tiles. Tests: tapping Carrot opens "How to cut carrot".

### Task 4: Docs, review, deploy
- spec.md Today's hour row; review; push; check live.
