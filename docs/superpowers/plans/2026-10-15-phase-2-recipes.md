# Phase 2: Recipes, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Your recipe library in the app. It holds your 9 recipes, converted to the two-phase format (8pm prep, then dinner finish), plus a starter set of component recipes. Each recipe has a card scaled to the household, with "in pantry" or "to buy" on every ingredient. Cook mode works on the iPad. Hero photos are generated by Google's image model. People can also be renamed in Settings.

**Architecture:**
- Recipes, ingredients and steps live in new Supabase tables, behind the same household access rules as Phase 1, and are loaded by a seed script from git-ignored JSON. The repo is public, and the HelloFresh content isn't ours to publish.
- Images live in a Supabase Storage bucket.
- An Edge Function (`generate-hero`) calls the Gemini Interactions API using the `GOOGLE_AI_API_KEY` secret. A local script runs it once for every recipe that has no hero photo.

**Tech Stack:** As in Phase 1, plus Supabase Storage and a Supabase Edge Function (Deno). Image model: `gemini-3.1-flash-lite-image` (Gemini Interactions API, `POST /v1beta/interactions`, `response_format.type: "image"`, `aspect_ratio: "4:3"`, `image_size: "1K"`).

**Spec:** `docs/spec.md`: §3 (house rules, toddler salt, kitchen), §4 Recipes tables, §5 Recipe format and Images, §6 Recipe library, recipe card and cook mode, §11 Phase 2.

## Global Constraints

- **Privacy:** recipe content (HelloFresh conversions and your own recipes) goes in `seed/private/recipes/` (git-ignored). Only a generic example recipe is committed.
- **Copy:** no HelloFresh branding in the UI. The source is shown as "HelloFresh, converted".
- **Toddler salt:** each recipe stores `salt_per_portion_g` where it's known. The card shows a toddler note whenever the toddler's share exceeds 0.5g (toddler weight × salt per portion).
- **Household portions:** come from `householdPortions(members)` (Phase 1). Scaling presets are household total, 6 and 9.
- **Quantity display:** g/ml are rounded to 5 above 50, kg/L from 1000, counts to the nearest ½, and an approximate quantity shows as "to batter consistency (about 100g)".
- **Pantry label:** "In pantry" when the ingredient name matches a staple with status `have` or `low`. Otherwise "To buy".
- **Machine badge:** TM7, APO, HY 24L, MEATER, Hob, Oven or Kettle, plus the settings text, in the mono "LCD" style from the mockup.
- **Images:** generated images carry a ✨ marker. One image costs about $0.034. The batch script prints the count and asks for `--yes` before generating.
- **Keys:** no Google key in the repo or `.env`. It lives only in Supabase Edge Function secrets.
- Layout rules are unchanged: phone and iPad, 16px gutters, inputs ≥16px, tokens from `tokens.css`.

## Review Focus

1. **A recipe with no hero image yet, or a failed generation.** The card still looks finished (tinted placeholder plus the title), never a broken image. *(Task 4)*
2. **Scaling to an odd total such as 3.25 or 5.5.** Quantities stay readable: no "0.33 egg" and no "1.0000001 tsp". *(Task 3)*
3. **Cook mode when the screen locks or the timer runs in the background.** The timer shows the right remaining time when you come back (it's worked out from an end time, not by counting ticks). *(Task 5)*
4. **Uploading a step photo with no signal, or a huge HEIC from the iPhone.** You get a clear error and the step keeps its old picture. Images are resized before upload. *(Task 5)*
5. **The seed run twice, or after a recipe has been edited.** No duplicate recipes, and steps and ingredients are replaced, not appended. *(Task 6)*

### Task 7: Hero image generation
**Files:** Create `supabase/functions/generate-hero/index.ts`, `src/lib/heroPrompt.ts` + test, and `scripts/generate-heroes.mjs`.
**Produces:**
- `heroPrompt(recipe): string`. House style: natural window light, 45° angle, the same matte stoneware on a pale oak table, no text, no hands, no branding. It names the dish and its 3–5 main ingredients.
- **Edge Function:**

- **Script:** `generate-heroes.mjs` lists recipes without a hero, prints "N images, about $X", and needs `--yes`. It then calls the function one recipe at a time.
